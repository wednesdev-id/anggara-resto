# ANGARA — Heritage Charcoal Hearth & Provincial Spice Table

> Sebuah landing page restoran fine dining mewah yang terinspirasi dari estetika editorial New York, dipadukan dengan psikologi warna makanan (*Culinary Hearth Palette*), branding orisinal bebas hak cipta, serta sistem interaktivitas lengkap.

---

## 🍽️ Tentang Proyek

**ANGARA** adalah eksplorasi desain web kuliner yang merayakan seni memasak api perapian dan rempah pusaka dari pedalaman desa (seperti Bihar, Malabar, Kashmir, dan Awadh). 

Proyek ini dibangun menggunakan **Vanilla HTML5, Modern CSS3, dan Vanilla JavaScript** tanpa ketergantungan library berat, menghasilkan performa super cepat (*zero-latency*), responsif penuh, dan ramah SEO.

---

## ✨ Fitur Utama

- **Bespoke Luxury Branding**: Lambang vektor emas *Sacred Hearth Crest* dan tipografi *Roman Serif* bertaraf internasional.
- **Palet Warna Psikologi Makanan**:
  - *Spiced Terracotta & Paprika* (`#852210`): Mempercepat respon nafsu makan dan kehangatan.
  - *Smoked Charcoal Hearth* (`#140E0D`): Memberikan kontras intim dan kemewahan santap malam.
  - *Saffron Gold & Turmeric* (`#E8A232` / `#F8C355`): Aksen pusaka kerajaan dan bumbu berkualitas tinggi.
  - *Crisp Editorial White* (`#FFFFFF`): Seksi ulasan pers gaya koran terkemuka.
- **Struktur Layout Teruji**:
  - *Full-Width Hero Food Photography* tanpa teks penutup yang mengganggu.
  - *2-Column Story & Founders Showcase*.
  - *Curated PDF Menus (2 di atas, 1 di tengah bawah)*.
  - *Printed Restaurant Menu 2 Kolom* dengan harga rata kanan dan deskripsi bahan jelas.
  - *Reviews & Press* bergaya koran (The New York Times, Esquire, Eater, Time Out, New York Magazine).
  - *Make a Reservation & Footer* dengan tombol kapsul elegan.
- **Interaktivitas & Portofolio Polish**:
  - **Floating Live Status Bar**: Indikator meja buka dengan tombol pesan cepat.
  - **Sistem Pemesanan Meja Instan**: Modal reservasi bergaya Resy dengan tiket digital berkode unik (e.g. `#ANG-XXXXX`).
  - **Pratinjau Fasimil Buku Menu**: Modal pembaca PDF menu beresolusi tinggi.
  - **Dukungan Dwibahasa (Bilingual)**: Tombol ganti bahasa instan antara Bahasa Indonesia (ID) dan English (EN).
  - **Quick Dish Inspector**: Modal detail bahan baku dan daerah asal hidangan.

## 🚀 Cara Menjalankan Secara Lokal

1. Clone repositori ini:
   ```bash
   git clone https://github.com/wednesdev-id/anggara-resto.git
   cd anggara-resto
   ```

2. Jalankan server lokal sederhana (pilih salah satu):
   * Menggunakan Python:
     ```bash
     python -m http.server 3000
     ```
   * Menggunakan Node.js / npx:
     ```bash
     npx serve .
     ```
   * Atau cukup buka file `index.html` langsung di browser Anda.

3. Kunjungi `http://localhost:3000` di peramban Anda.
